# Product spec (from the Intern LMS and the project charter)
**Purpose:** replace manual checking of Tech Pub wiring-diagram JPGs against the OEM PDF with an AI-assisted verifier a customer can pay for.
**Inputs:** OEM wiring PDF(s), Tech Pub sheet images, component list (HX Codes, NEW CODE authoritative), brand rule set (Hyundai VDH first).
**Outputs:** per-wire results, findings, green/yellow/grey/blue destination classes, font-standard candidates, multi-tab Excel report with prompt version.
**Not claimed:** final pass/fail authority. A reviewer signs off.
**Release checklist:** server-side key | zero fabricated entries on the golden set | website results match direct-run scores | lead sign-off | internal pilot.
**Later (charter):** pricing tiers, benchmark reports, dashboard history, more standards.
